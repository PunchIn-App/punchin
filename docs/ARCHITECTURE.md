# PunchIn — Architecture & File Map

> **Canonical home for the full annotated repository structure**, extracted from `CLAUDE.md` to keep that file lean. **Read this when you need to know what a specific module does, or before adding, moving, or renaming a file.** When you add / rename / remove a file, update the tree here — `CLAUDE.md` → Documentation Maintenance points back to this file.

## Repository structure

├── wrangler.jsonc          # Cloudflare Workers deployment; deploy via `npm run deploy`; routes OAuth requests to worker/oauth.js and static assets via ASSETS binding

│   │   ├── tokenStore.js       # At-rest encryption of the sync tokens (issues #126, #243): setSyncToken/getSyncToken/clearSyncToken + setRefreshToken/getRefreshToken, backed by the `secrets` table (non-extractable AES-GCM key). Lazily migrates a legacy plaintext settings.syncToken. Also getFreshAccessToken() — the single access-token chokepoint every sync goes through: returns a usable token, SILENTLY REFRESHES it via the worker (/oauth/refresh) when expired and a refresh token is stored (single-flight so a manual-vs-periodic race can't double-spend a rotated Microsoft token), or throws TOKEN_EXPIRED when it can't be refreshed (no refresh token, or the refresh token is dead). runSync/disconnectSync/App.jsx go through this — neither token is ever in plaintext IndexedDB
│   │   ├── syncManager.js      # Core sync logic: exportSnapshot (data + portable preferences), mergeSnapshot (reuses import dedup; `{applySettings}` gate), importSnapshot (public merge for transfer links, issue #77 — applies preferences, an explicit user import), runSync (pull→merge→push; seeds preferences into a FRESH install only, never overwriting an established device), disconnectSync (deletes the device gist file, then best-effort revokes this device's access via the worker /oauth/revoke — GitHub device-scoped so other devices keep syncing; Google revokes the REFRESH token, cascading to the whole grant; OneDrive has no client-side revoke, relying on prompt=select_account — then wipes both tokens + sync settings). runSync pulls its access token from tokenStore.getFreshAccessToken()

Trailing-edge throttle + runSync's idempotent merge keep it loop-safe; only the actionable TOKEN_EXPIRED is surfaced — background ticks swallow transient/network errors. Driven by the useAutoSync hook
│   │   └── providers/
│   │       ├── github.js       # GitHub Gist API: buildGitHubOAuthUrl, fetchGitHubUser, findExistingPunchInGist, createGist (marker + device file), fetchAllDeviceData (reads all punchin-data-*.json + legacy file), pushDeviceData (writes marker + own device file), deleteDeviceFile (nulls file on disconnect), updateGist/fetchGist (legacy, kept for backward compat)
│   │       ├── google.js       # Google Drive API: buildGoogleOAuthUrl (Auth Code flow via the worker, appdata + `openid email` scopes, access_type=offline + prompt=consent so a refresh token is (re)issued, issue #243; select_account keeps the account chooser), pushToDrive, pullFromDrive, fetchGoogleUser (GET userinfo → email, for the connect-confirm dialog)
│   │       └── onedrive.js     # Microsoft Graph API: buildOneDriveOAuthUrl (Auth Code flow via the worker as a confidential client, AppFolder + User.Read + offline_access scope for a 90-day refresh token, issue #243 — supersedes the public-SPA + PKCE flow of #128; prompt=select_account keeps the account chooser), pushToOneDrive, pullFromOneDrive, fetchOneDriveUser (GET /me → account identity, for the connect-confirm dialog)

│   ├── accentPresets.js    # Single source of truth for the accent presets (the AppearancePanel swatches) + accentIconKey() + DEFAULT_JOB_COLOR (shared on-palette fallback for an uncoloured job/labor type); shared by the settings UI, installIcon.js, and iconPalette.js (issue #228)
│   ├── iconSvg.js          # The brand mark as an SVG string (stopwatch glyph on a rounded accent square; glyph tinted white/dark-ink via utils/inkOnAccent for contrast). Stores h*60+m minutes, snaps off-grid values, switches the reminder off at 0h 0m. Wheel CSS (`.wheel-col`, with a fade mask) in `index.css`. Issue #111).
